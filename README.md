# Bean Boutique Coffee Shop

A responsive multi-page coffee shop website built with HTML, CSS, and JavaScript.

## About the Project

Bean Boutique is a frontend coffee shop website designed to provide
customers with an engaging and user-friendly online coffee experience.

The website allows users to explore coffee products, brewing equipment,
events and workshops, special offers, subscriptions, blog content,
and shopping cart features.

## Features

- Responsive navigation
- Mobile-friendly menu
- Hero image slider
- Coffee selection
- Coffee search
- Brewing equipment catalogue
- Add to cart functionality
- Shopping cart
- Special offers
- Coffee subscription plans
- Events and workshops
- Event registration
- Blog section
- Our Story page
- Responsive design

## Pages

- Home
- Coffee Selection
- Brewing Equipment
- Events & Workshops
- Special Offers & Subscriptions
- Blog
- Our Story
- Shopping Cart

## Technologies

- HTML5
- CSS3
- JavaScript
- Font Awesome

## Design

The website focuses on a warm and modern coffee-shop aesthetic,
with responsive layouts and interactive frontend components.

## How to Run

1. Clone this repository.

2. Open the project folder in Visual Studio Code.

3. Open `index.html`.

4. Run the project using Live Server.
